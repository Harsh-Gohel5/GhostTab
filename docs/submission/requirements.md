## Requirements visible in the supplied screenshots

- Public repository, accessible video link, and all people who worked on the
  project listed in the submission.
- One project submission per team/startup, with one designated representative.
- A three-minute demo video showing the specific features, code and functionality
  built during the hackathon. Judges must be able to identify that contribution.
- Teams of up to four; solo participation is allowed.
- Initial pass/fail screening for viability, theme fit, and reasonable use of Meta
  Model API and/or Meta open-weight models.
- Scoring: Impact 30%, Meta AI tooling 25%, Technical Depth & Execution 20%, Demo 25%.

These screenshots do not establish the complete originality, licensing or
AI-assistance policy. Obtain the remaining rules and current submission fields
before claiming full compliance. The public page explicitly presents coding-agent
tools as part of the event offering; that alone does not settle disclosure rules.
